# Base de conhecimento do produto

Abra esta pasta como vault no Obsidian ou navegue pelos Markdown no GitHub. Nenhum plugin é necessário.

- [Processos](processos/README.md): descrições de processos e regras de negócio validadas.
- [Projetos](projetos/README.md): contexto e aprendizado do produto.
- [Referências](referencias/README.md): fontes, documentos e divergências.

Use títulos claros e links relativos. Cada documento deve registrar origem, responsável, última revisão, estado de validação e restrição de acesso. Conteúdo sem evidência de aprovação deve ser rotulado como rascunho/proposta.

Não copie dados pessoais, bases operacionais, segredos ou documentos cujo público autorizado seja mais restrito que o repositório. Registre a referência ao local corporativo autorizado. Não publique nem sincronize o vault com terceiros sem autorização. Configurações pessoais e plugins do Obsidian não devem ser versionados.
